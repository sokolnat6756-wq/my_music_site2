# Наталья Сокол — сайт авторских песен

Лендинг для презентации авторских и персональных песен на заказ.
Статический сайт на HTML + Tailwind CSS (CDN) + ванильный JavaScript.
Никакого сервера не требуется — достаточно открыть `index.html` в браузере или залить файлы на любой хостинг.

## Содержание

```
.
├── index.html              ← главная страница
├── assets/
│   ├── css/styles.css      ← кастомные стили (плеер, модалка, анимации)
│   ├── js/app.js           ← вся логика сайта
│   └── audio/              ← сюда положить MP3-файлы песен
│       ├── song-1.mp3
│       ├── song-2.mp3
│       └── song-3.mp3
└── README.md               ← этот файл
```

## Быстрый запуск

1. Откройте `index.html` двойным кликом — сайт сразу заработает в браузере.
2. Для нормальной работы аудио и форм лучше открывать через локальный сервер
   (некоторые браузеры блокируют автоплей и `file://`):
   - VS Code: установите расширение **Live Server** → ПКМ по `index.html` → *Open with Live Server*.
   - Python: в папке проекта выполните `python -m http.server 8000` и откройте `http://localhost:8000`.

## Настройка (ОБЯЗАТЕЛЬНО)

### 1. Контакты — Telegram и WhatsApp

Откройте `assets/js/app.js` и в самом верху найдите блок `CONFIG`:

```js
const CONFIG = {
  telegramUsername: "your_telegram",     // ← ваш Telegram без @
  whatsappPhone: "79991234567",          // ← ваш WhatsApp без + и пробелов
  defaultMessage: "Здравствуйте, Наталья! Хочу заказать у Вас песню."
};
```

Замените значения на свои:

| Поле | Где взять | Пример |
|------|-----------|--------|
| `telegramUsername` | Откройте Telegram → Настройки → Имя пользователя | `natalya_sokol` |
| `whatsappPhone` | Ваш номер в международном формате, **без `+`, пробелов и дефисов** | `79991234567` |
| `defaultMessage` | Текст, который подставится в чат при клике на «Написать в Telegram» / «WhatsApp» | любой |

### 2. Аудио-треки

Положите MP3-файлы в `assets/audio/`:

- `song-1.mp3` — Песня для мамы
- `song-2.mp3` — Свадебная песня
- `song-3.mp3` — Песня для любимого человека

Если файл отсутствует, плеер автоматически покажет «трек скоро появится» — сайт не сломается.

Чтобы поменять названия песен или количество карточек — отредактируйте секцию `<!-- SONGS -->` в `index.html`:

```html
<div class="custom-player mt-5"
     data-src="assets/audio/song-1.mp3"
     data-title="Песня для мамы">
</div>
```

### 3. Тексты, фото, отзывы

Все тексты — прямо в `index.html`, поиском по разделам:
- `<!-- HERO -->` — главный экран
- `<!-- ABOUT -->` — о Наталье
- `<!-- REVIEWS -->` — отзывы
- `<!-- CONTACT -->` — призыв заказать

Фоновые фото взяты с Unsplash. Чтобы заменить — поменяйте URL в `style="background-image:url(...)"` на ваш файл (например, `assets/img/hero.jpg`).

## Что уже работает

- Адаптивный дизайн (мобильное меню с бургером).
- Плавная прокрутка к секциям.
- Анимации появления при скролле.
- Кастомный плеер: своя кнопка play/pause, перемотка кликом по полосе, отображение времени, только один трек играет одновременно.
- Модальное окно «Заявка на песню» с валидацией.
- При отправке формы открывается Telegram **или** WhatsApp с готовым красивым сообщением — клиенту останется только нажать «Отправить».
- Прямые ссылки в шапке и контактах ведут в Telegram/WhatsApp с приветственным сообщением.
- Плавающая кнопка «Заказать песню» появляется после прокрутки.
- SEO-метаданные и Open Graph (для красивого превью при шеринге).
- Уважает настройку «уменьшить движение» (prefers-reduced-motion).

## Деплой

Сайт чисто статический — можно положить на любой хостинг:

- **GitHub Pages** — закиньте файлы в репозиторий → Settings → Pages → выбрать ветку.
- **Netlify / Vercel** — drag-and-drop папки на сайт сервиса.
- **Beget / Timeweb / любой обычный хостинг** — залейте файлы по FTP в корневую папку.

Никакой сборки, npm install и Node.js не нужно.
